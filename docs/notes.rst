Working notes
=============

These stay in Markdown next to the pages, as they are records of how something was done or measured
rather than documentation of how it is. So they say what was true when they were written.

* :src:`docs/benchmark.md`: how to measure, the tools that work on the development host, and what has
  been measured so far.
* :src:`docs/corosio-port-plan.md`: how the COROSIO API style came about, step by step, and what is
  left of it.
* :src:`docs/capy-corosio-lessons.md`: what the port taught about Capy and Corosio.
* :src:`docs/quic-streams-plan.md`: how plain QUIC streams got separated from HTTP/3.

:src:`CLAUDE.md` is how to work in the tree: the build trees and what each is for, the rules for
what may include what, and the traps.
